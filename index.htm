                <div class="lg:col-span-2 text-slate-600 space-y-4 text-justify text-sm">
                    <p>
                        <strong>Fractional distillation</strong> is a critical chemical engineering unit operation used to separate binary or multi-component liquid mixtures into their pure components based on differences in their boiling points (relative volatility) [1, 23]. The process takes place in a vertical column where vapor rises and liquid descends, creating counter-current intimate contact on multiple trays or plates [1, 24].
                    </p>
                    <p>
                        A standard distillation column with a middle feed is divided into two main zones:
                    </p>
                    <ul class="list-disc pl-5 space-y-2">
                        <li>
                            <strong>Rectifying (Enriching) Section:</strong> Located above the feed plate [1]. In this section, the vapor is enriched in the more volatile component (Heptane) as it rises. Liquid reflux from the condenser flows down, washing out the less volatile component (Octane) [1, 24].
                        </li>
                        <li>
                            <strong>Stripping (Despojo/Agotamiento) Section:</strong> Located below the feed plate [1]. Here, the descending liquid is stripped of the more volatile component by the rising vapor generated in the reboiler, leaving a bottoms product concentrated in the heavy key [1, 25].
                        </li>
                    </ul>
                    <p>
                        This simulator models the mass and equilibrium behaviors on a single plate. Under the <em>Sorel-Lewis</em> assumption (constant liquid and vapor molar flow rates), we can use linear interpolation of the vapor-liquid equilibrium (VLE) data alongside the plate mass balance to determine all key composition streams entering and leaving a plate [3, 25, 30].
                    </p>

        // Interpolation logic
        function interpolateX(yVal) {
            if (yVal <= 0) return { x: 0, temp: 125.60, p1: vleData[0], p2: vleData[0] };
            if (yVal >= 1) return { x: 1, temp: 98.41, p1: vleData[vleData.length - 1], p2: vleData[vleData.length - 1] };

            for (let i = 0; i < vleData.length - 1; i++) {
                const p1 = vleData[i];
                const p2 = vleData[i + 1];
                if (yVal >= p1.y && yVal <= p2.y) {
                    const ratio = (yVal - p1.y) / (p2.y - p1.y);
                    const xVal = p1.x + ratio * (p2.x - p1.x);
                    const tempVal = p1.temp + ratio * (p2.temp - p1.temp);
                    return { x: xVal, temp: tempVal, p1: p1, p2: p2 };
                }
            }
            return { x: 0, temp: 125.60, p1: vleData[0], p2: vleData[0] };
        }
